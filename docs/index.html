04

De la unua instrukcio al konservado

Ĉiu paŝo havas pruvon: starto, haketo, provaĵo aŭ verda DI-rezulto.

  1. M0Plenumita

    Laborloko kaj konstrua ĉeno

    Tri kestoj, unu konstruo.

  2. M4Plenumita

    GDT, IDT, TSS

    256 vektoroj kaj int 0x80-pordego.

  3. M7Plenumita

    Antaŭokupa planisto

    Rondiga planisto kun ok fadenoj.

  4. M8Plenumita

    Mesaĝa IK

    Finpunktoj, kapabloj, blokado kaj vekado.

  5. M11Plenumita

    Ring 3

    int 0x80 el uzantspaco.

  6. M12Plenumita

    Per-procesaj spacoj

    Spiono ricevas #PF; la viktimo pluvivas.

  7. M13Plenumita

    Memoro-firmigo

    SMEP, SMAP kaj KASLR.

  8. M15Plenumita

    arm64

    EL0, ABI 2, ramfb kaj PAN.

  9. M17Nun

    Konservado

    virtio-blk tra PCI kaj MMIO; SNDS kun 4 dosieroj.

  10. M18Parte

    DI kaj pruvaro

    43/43 taskoj verdaj; testoj ankoraŭ venas.
